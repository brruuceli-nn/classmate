# 05_calc_billion_table

这80亿人口是怎么一步步增长起来的呢？我们一起来看左侧教材上的《世界人口增长示意》图，大家一起动脑心算一下，从1830年开始，全球每增加10亿人分别需要花费多少年？来，我们对一下结果：从10亿到20亿用了100年，20亿到30亿缩短到30年，30亿到40亿15年，接着连续三个阶段都是12年，从70亿到80亿只用了短短11年！每增加10亿人口经历的时间大大缩短了。

# 06_growth_curve_base

非常棒！那我们将刚才的数据按时间顺序绘制成曲线，就可以更直观地看出世界人口数量的变化趋势：18世纪以前，人口增长十分缓慢；工业革命后，人口增长的速度大大加快；第二次世界大战后，世界人口迅速增长。那请同学们深入思考一下：近些年来世界人口增长速度已经放缓，为什么每年地球上新增加的人口数量仍然很多呢？对啦，因为世界总人口的基数太大了，高达80亿，哪怕增速放缓一点，每年净增的人口数量依然非常庞大。

# 14_density_misconception

在这里，督导要考大家一个非常容易混淆的概念：是不是只要人口密度大，这个国家的总人口就一定很多呢？那人口密度是怎么计算的？看大屏公式：人口密度等于总人口除以面积。比如新加坡国土面积很小，人口密度极高，但总人口只有约六百万。所以大家一定记牢：人口密度只反映人口分布的疏密程度，绝不能直接等于人口多少！

# 15_queue_contrast

进入环节三！我们找到了人口密集区，但是惊奇地发现：同样都位于人口稠密区，有的城市蜜雪冰城门口年轻人排起长队，门店越开越多；而有的城市门口冷清无人排队，来往行人大多都是中老年人，全城只开了几家店。这又是什么原因导致的呢？老师提醒大家一下，一般买奶茶的都是什么年龄阶段的人群？对，主要是年轻人！所以我们选址最好开在年轻人多的地区，这就涉及到了一个新的地理概念——人口自然增长率。

---

# 16_natural_growth_formula

人口自然增长率怎么算呢？请在我们的课本上找到并画下来：人口自然增长率等于出生率减去死亡率。当人口自然增长率大于0的时候，出生率高于死亡率，总人数在增加，此时一般年轻人较多；当自然增长率等于0的时候，总人数保持不变；当它小于0的时候，人口出现负增长，总人数减少，人口老龄化现象就会出现。

---

# 17_warmup_calc

我们来热身算一算！已知某地出生率为百分之十六，死亡率为百分之七，那该地的自然增长率是多少呢？人口总数怎么变化？大家算得真快，一起看大屏结果：百分之十六减去百分之七等于百分之九，因为大于0，所以该地的人口总数在不断增加！

# 19_growth_impacts

通过雅加达和东京这两座城市，我们再跳出奶茶看世界：人口自然增长率除了对奶茶营销有影响外，对社会其他方面有怎样的影响呢？大家看图归纳：如果人口增长过快，就会带来交通拥堵、住房紧张、就业压力大等问题；反过来如果人口增长过慢甚至负增长，就会导致人口老龄化、消费活力下滑、国防兵源不足、社会养老负担加重等一系列难题。

# 20_harmony_conclusion

既然增长过快有问题，增长过慢也有烦恼，那么到底人口怎样增长才是最好的呢？全班一起大声说出这句核心结论——人口增长要与发展相协调！也就是人口的增长必须与资源、环境相协调，与社会、经济发展相适应。
